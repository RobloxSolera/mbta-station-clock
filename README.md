# MBTA Train Countdown Clock

This project is a simple digital display of the next MBTA Red Line train to **Alewife** (or any station you choose). It fetches real-time data from the MBTA API and displays:

- **Time remaining** until the next train.
- **Current time**.
- **Announcements** when the train is about to arrive (within 1 minute).
- **Train status** (e.g., approaching, now boarding).
- **Platform warnings** (e.g., "Please stand back from the platform edge").

## Features:
- Real-time countdown of the next train.
- Announcements when the train is approaching.
- Displays live service alerts and diversions (optional).

## How to Use:
1. Clone the repository or download the `index.html` file.
2. Upload it to a hosting platform like **GitHub Pages**, **Render**, or **Netlify**.
3. Once hosted, open the URL to view the **train countdown** and announcements.

## Deployment:
